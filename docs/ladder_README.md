# 🏆 2026 CANN 算子天梯赛 

> **大赛简介**
> CANN 算子天梯赛，是面向全社会 AI 算子工程师的长期算子性能极限挑战赛，基于昇腾平台对算子进行长期优化打榜，按月度结算奖励性能榜首，为每一位算子开发者提供绝佳的实践平台。

>天梯赛的算子题目来源于真实的场景需求，目的是让参赛者持续优化的算子可以合入CANN算子库并在真实场景发挥作用。因此天梯赛算子禁止只针对特定shape进行编程，需要参赛者实现泛化的算子以满足实际场景不同算子规格的要求。

## ⚖️ 赛事规则

* 🎯 **参赛对象要求**：面向全社会开发者。
* 📝 **参赛答题要求**：参赛选手需要根据赛题赛规要求，在指定时间内完成报名、组队、作品提交，方为有效参赛。(每天最大提交次数为50次，取最优成绩为最后成绩记录)
* 🤝 **组队要求**：先报名后组队，每支队伍 1-3 人。
* 🛡️ **公平参赛**：每个阶段比赛结束后，大赛组委会将进行代码查验。如发现代码重复或违规等情况，将直接取消该队伍参赛资格和现有成绩。
* ⚔️ **比赛机制**：
  1.  天梯赛长期举办，每月最后一天下午5:00结算当月排名，每个算子题目独立评选一个月度冠军，在此之后的提交不计入当月成绩
  2.  新赛题每题首月性能排行前三名获奖，获奖发放AtomGit商城CANN专属积分（可兑换奖品），单题总积分=题目难度*2000  * 100，分别获取该题积分的60%，30%，10%
  3.  跨月赛题当月性能前三名提交且超过历史最佳提交性能3%以上获奖，计算方式为所有测试用例耗时总和提升比例大于3%
  4. 只有天梯赛获奖人员可以在AtomGit CANN专属商城中兑换奖品
  5.  每个算子独立评选前三名，需满足精度达标且性能符合上述要求
  6.  每一道赛题连续两个月排名第一的获奖者不可以是同一人
  7.  算子要求具备泛化性，满足赛题中的shape范围，禁止只针对测试用例shape进行编程
  8.  比赛每月封榜后会对算子进行泛化性验收测试，通过验收阶段才给予奖励
  9.  每月单人最多获奖三道赛题，优先奖金级别最高的三道题
 * ⚠️**赛题要求**：
  1.  请开发符合题目语义、精度要求和全部合法输入范围的通用 Ascend C 算子，优化重点必须在 NPU Kernel 侧。Host 仅负责参数校验、Shape 推导、Tiling 和启动配置，不得读取输入张量数值代算或提前生成结果。
  2.  每次调用必须基于本次输入正确完成任务，禁止硬编码答案、按测试用例或数据生成规律跳算、跨调用缓存回放、写入标记跳过计算，以及利用旧输出或未初始化内存。
  3.  允许基于 Shape、对齐和硬件资源进行通用优化，但不得逐条匹配评测用例编写专属实现，也不得擅自假定输入全零、全一或数值范围更小；所有优化分支必须保证适用范围内正确，并为其他合法输入提供正确路径。
  4.  禁止修改或干扰判题、精度校验和计时流程，禁止注入空核、识别预热轮次或把实际计算移出计时范围。性能提升必须来自真实算法和 Kernel 优化。
